### Scrub and search

Prediction: Search is True; five whitespace-separated words. Removing punctuation without inserting spaces joins AGENT, Falcon, and reports.

```python
# CODE_RUNNER: Scrub and search
noisy = "   ...AGENT>>>Falcon---reports: the PACKAGE has ARRIVED!!!   "
trimmed = noisy.strip()
cleaned = trimmed.replace(">", "").replace("-", "").replace("!", "")
lowered = cleaned.lower()
has_arrived = "arrived" in lowered
words = cleaned.split()
print("Trimmed:", repr(trimmed))
print("Cleaned:", cleaned)
print("Lowered:", lowered)
print("Contains 'arrived':", has_arrived)
print("Word count:", len(words))
assert has_arrived and len(words) == 5
```


### Crack the final transmission

Prediction: Four fields, year check True, dawn found True. The decoded message is THE EAGLE LANDS AT DAWN.

```python
# CODE_RUNNER: Crack the final transmission
raw_transmission = "  2026-09-15,GHOST,THE-EAGLE-LANDS-AT-DAWN,87  "
segments = raw_transmission.strip().split(",")
date, agent, message_code, confidence_str = segments[0], segments[1], segments[2], segments[3]
year_check = date[:4] == "2026"
message = message_code.replace("-", " ")
found_dawn = "dawn" in message.lower()
markdown_row = f"| {date} | {agent} | {message} | {confidence_str}% |"
json_line = (f'{{"date": "{date}", "agent": "{agent}", "message": "{message}", '
             f'"confidence": {confidence_str}, "contains_dawn": {str(found_dawn).lower()}}}')
print("Segments:", segments)
print("Date:", date, "| Agent:", agent, "| Message code:", message_code, "| Confidence:", confidence_str)
print("Year check:", year_check)
print("Found 'dawn':", found_dawn)
print("Markdown row:", markdown_row)
print("JSON line:", json_line)
assert len(segments) == 4 and year_check and found_dawn
```

**Actual output**

```text
Segments: ['2026-09-15', 'GHOST', 'THE-EAGLE-LANDS-AT-DAWN', '87']
Date: 2026-09-15 | Agent: GHOST | Message code: THE-EAGLE-LANDS-AT-DAWN | Confidence: 87
Year check: True
Found 'dawn': True
Markdown row: | 2026-09-15 | GHOST | THE EAGLE LANDS AT DAWN | 87% |
JSON line: {"date": "2026-09-15", "agent": "GHOST", "message": "THE EAGLE LANDS AT DAWN", "confidence": 87, "contains_dawn": true}
```

## Explanation

Strings are immutable: methods return new values, so each cleaned result is assigned. Negative indexing counts backward; slices exclude their stop. The f-string JSON is suitable for these fixed safe fields; arbitrary quoted user text would need a JSON serializer. Simple split handles this unquoted example, not general CSV with embedded commas. No imports or input calls are needed.
