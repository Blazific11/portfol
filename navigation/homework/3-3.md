### Weekly costs and booking capacity

Prediction: Costs 105 and 420; booking results 12, 88, 44.0. Both versions of the lesson’s Popcorn 2 prompt are covered.

```python
# CODE_RUNNER: Weekly costs and booking capacity
cost_per_session, sessions_per_week, weeks_per_month = 35, 3, 4
weekly_cost = cost_per_session * sessions_per_week
monthly_cost = weekly_cost * weeks_per_month
print("Weekly cost:", weekly_cost)
print("Monthly cost:", monthly_cost)
total_monthly_capacity, spots_requested_per_group, sessions_booked = 100, 4, 3
total_spots_taken = spots_requested_per_group * sessions_booked
remaining_capacity = total_monthly_capacity - total_spots_taken
users_per_room = remaining_capacity / 2
print("Total Spots Taken:", total_spots_taken)
print("Remaining Capacity:", remaining_capacity)
print("Users per Room:", users_per_room)
```

**Actual output**

```text

Monthly cost: 420
Total Spots Taken: 12
Remaining Capacity: 88
Users per Room: 44.0
```

### Recovery center cost report

Prediction: 105, 420, 495, and 14.0. The one-time fee is excluded from the monthly daily average.

```python
# CODE_RUNNER: Recovery center cost report
cost_per_session = 35
sessions_per_week = 3
weeks_per_month = 4
enrollment_fee = 75
weekly_cost = cost_per_session * sessions_per_week
monthly_cost = weekly_cost * weeks_per_month
total_cost_with_fee = monthly_cost + enrollment_fee
average_daily_cost = monthly_cost / 30
print("Weekly Cost:", weekly_cost)
print("Monthly Cost:", monthly_cost)
print("Total Cost with Fee:", total_cost_with_fee)
print("Average Daily Cost:", average_daily_cost)
assert (weekly_cost, monthly_cost, total_cost_with_fee, average_daily_cost) == (105, 420, 495, 14.0)
```
